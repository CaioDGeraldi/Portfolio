# Portfolio contributor instructions

Before modifying the homepage or its public-facing copy:

1. Read `DESIGN.md`; it is the visual and editorial source of truth.
2. Apply the audit sequence from the anti-slop-ui skill: https://github.com/nyrthoughts/anti-slop-design/tree/main/skills/anti-slop-ui
3. Apply the rewrite and self-audit rules from humanize-writing: https://github.com/shir-danishyar/humanize
4. Preserve all facts and distinctions between internship experience, personal products, collaborative projects and proposals.
5. Do not invent numbers, adoption, customers, institutional partnerships, production deployments or responsibilities.
6. Preserve bilingual copy, natural document scrolling, keyboard navigation, theme switching and prefers-reduced-motion behavior.
7. Test at 375px, 768px and 1280px or wider. Run `npm run build`, `npm run test:unit` and `npm run test:e2e` when available. Report only tests actually run.
