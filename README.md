# Portfolio

Portfólio pessoal de **CaioDGeraldi**, desenvolvido como site estático.

## Tecnologias

- HTML5
- CSS
- JavaScript
- Three.js
- Font Awesome

## Execução local

Abra `index.html` diretamente no navegador ou sirva a pasta com um servidor HTTP estático.

## Publicação

O projeto não possui backend nem etapa de build e pode ser publicado diretamente pelo GitHub Pages a partir da branch principal.
